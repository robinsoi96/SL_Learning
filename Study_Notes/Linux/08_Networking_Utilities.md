# Linux Networking Utilities

## `ip` Utility

1) `ip addr show` : Show all IP addresses
    - Same as commands like `ip addr`, `ip address`, `ip a`, `ip address show`, `ip a s`

2) `ip addr show <interface_name>` : Show IP address info of the network interface name

3) `ip -br addr show` : Show all IP addresses but in shorter form

4) `ip -br addr show <interface_name>` : Show IP address info of the network interface name but in shorter form

## `ifconfig` Utility

1) `ifconfig` : Show all IP addresses which are **UP** only

2) `ifconfig -a` : Show all IP addresses

3) `ifconfig <interface_name>` : Show IP address info of the network interface name
